Apa itu Cloud Computing?

Cloud computing adalah cara memakai server, penyimpanan, dan layanan komputer lewat internet, jadi kita tidak perlu beli dan merawat server sendiri. Biaya biasanya mengikuti pemakaian.

Tiga Model Layanan

IaaS (Infrastructure as a Service)

Kita dapat infrastruktur dasarnya seperti virtual machine dan jaringan. Contoh: Azure Virtual Machines.

PaaS (Platform as a Service)

Kita tinggal taruh aplikasi, urusan server dan sistem operasi dikelola penyedia. Contoh: Azure Static Web Apps, Vercel.

SaaS (Software as a Service)

Aplikasi jadi yang langsung dipakai lewat browser. Contoh: Gmail, Google Docs.

Yang Dikerjakan di Modul 1

  • Menjalankan file index.html di komputer sendiri
  • Membuat repository di GitHub dan mengunggah file
  • Menghubungkan GitHub ke Vercel lalu deploy
  • Membuka website lewat link yang sudah online

Tools yang Dipakai

  • Visual Studio Code untuk edit dan tes di lokal
  • GitHub untuk menyimpan kode
  • Vercel untuk hosting website

Update Versi 2.0

Setelah file diubah di GitHub, Vercel otomatis deploy ulang tanpa perlu klik Deploy lagi. Ini yang disebut Continuous Deployment.
